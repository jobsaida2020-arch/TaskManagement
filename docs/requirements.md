# 要件定義書

## 1. 概要・背景/目的

Trello風のタスク管理アプリ。個人利用を想定し、ログイン機能や複数人での共有は行わない。

**背景・目的**

本アプリはプログラミングスクールの学習課題として制作する。実務で使われるタスク管理アプリ(Trello等)を模したアプリを一人で企画・設計・実装することで、以下を習得することを目的とする。

- 要件定義〜設計〜実装〜(将来的な)DB連携までの一連の開発プロセスの経験
- フロントエンド(画面設計・状態管理)とバックエンド(API・DB設計)の基礎的な連携の理解
- ER図・画面遷移図など設計ドキュメントを自分で作成する経験

そのため、実際の顧客向けプロダクトではなく「学習目的で作る個人用アプリ」という前提で要件を定める。

## 2. 機能要件

タスクの追加・状態変更(未着手/進行中/完了)・削除・並び替え・ブラウザ保存の5機能を提供する。タスクはタイトル・説明文・期限・優先度・状態を持つ。

並び替えは列(未着手/進行中/完了)ごとに独立して設定でき、「優先度順」「期限順」のボタンによる自動ソートと、Trelloのようにカードを直接ドラッグして並べる自由な手動並び替えの両方に対応する。

- 機能一覧、タスクが持つ情報、ユースケース(UC1〜UC4)の詳細は [機能要件書](functional-requirements.md) を参照

## 3. スコープ外(今回は作らない機能)

- ログイン機能
- 複数人での共有
- 期限切れタスクの強調表示など、期限に関する特別な表示(将来的に追加検討)

## 4. データの保存方法

現状はサーバーやデータベースは用意せず、ブラウザ内にデータを保存する(localStorage)。
将来的にバックエンド(自作)とDBを用意し、ブラウザ保存からDB保存へ切り替える予定(詳細は「6. データ設計」を参照)。マルチユーザー対応は現時点では不要。

## 5. 優先度の初期値・並び順(補足)

優先度は「高・中・低」の3段階とする。初期値は「中」。色分けなどの見た目の扱いは今後決定する。

並び替えは列ごとに以下の3モードを切り替えられる。

| モード | 内容 |
|--------|------|
| 手動 | カードをドラッグ&ドロップして自由な順序に並び替える(デフォルト) |
| 優先度順 | 高→中→低の順に並び替える。同一優先度内は手動順を維持する |
| 期限順 | 期限が近い順に並び替える。期限未設定のタスクは末尾に表示する。期限が同じ場合は手動順を維持する |

カードをドラッグして手動で並び替えると、その列の並び替えモードは自動的に「手動」に切り替わる(自動ソート中に手動で動かした場合も同様)。

## 6. データ設計

エンティティは「タスク」1つのみ(マルチユーザー非対応)。バックエンド・DBの技術構成は未確定のため、特定のDB製品に依存しない論理レベルのER図として管理する。

- ER図・テーブル定義の詳細は [データ設計(ER図)](data-design.md) を参照

## 7. 画面設計・画面遷移

ボード画面1つのみを想定し、タスクの追加・編集はモーダルで行う(タスク詳細ページ等は作らない)。未着手・進行中・完了の3列を横に並べ、タスクカードは列間を移動できる。

- 画面構成・画面遷移図の詳細は [画面構成・画面遷移](screens.md) を参照

## 8. 非機能要件(たたき台)

学習目的の個人アプリのため簡易な内容とする。今後の実装状況に応じて見直す。

| 項目 | 内容(たたき台) |
|------|----------------|
| 対応ブラウザ | 最新版の Google Chrome を主対象とする(他ブラウザは動作保証しない) |
| 想定データ量 | 保持タスク数は目安として最大100件程度を想定する |
| レスポンス速度 | タスクの追加・移動・削除などの操作は体感1秒以内に画面へ反映される |
| 稼働環境 | 個人のPC上での利用を想定し、常時稼働・可用性は考慮しない |
| データの永続化 | ブラウザを閉じても、または端末を再起動してもタスク情報が消えないこと(localStorage、将来的にはDB) |
| セキュリティ | ログイン機能なし・個人利用前提のため認証・認可は考慮しない。個人情報や機密情報は登録しないことを前提とする |
| 保守性 | 学習目的のため、コードの可読性を優先し、過度な最適化・抽象化は行わない |

## 9. スコープ外・保留事項

- 期限切れタスクの強調表示など、期限に関する特別な表示(将来的に追加検討)
- 優先度の色分け(5章、保留。並び順・初期値は決定済み)
- 変更履歴・改訂管理(保留)
