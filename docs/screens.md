# 画面構成・画面遷移

親ドキュメント: [要件定義書](requirements.md)

ボード画面1つのみを想定し、タスクの追加・編集はモーダルで行う(タスク詳細ページ等は作らない)。

## 1. 画面構成(ボード画面)

```mermaid
flowchart LR
    subgraph Board["ボード画面"]
        Col1["未着手 列"]
        Col2["進行中 列"]
        Col3["完了 列"]
        AddBtn["＋ ボタン"]
        SortBtn["並び替えボタン(手動/優先度順/期限順)"]
    end
```

- 未着手・進行中・完了の3列を横に並べて表示する
- 各列にその状態のタスクをカード形式で表示する
- タスクカードは列間をドラッグ&ドロップ、または操作(移動ボタン等)で移動できる
- 「＋」ボタンはボード画面上(列ごと、または画面共通)に配置する
- 各列には「手動」「優先度順」「期限順」の並び替えボタンを配置し、列ごとに独立して並び替え基準を選択できる
- 「手動」選択時は、列内でタスクカードを直接ドラッグ&ドロップして自由な順序に並び替えられる(列間の移動と同じドラッグ操作で、同一列内に落とすと順序変更になる)

## 2. 画面遷移(モーダルの開閉)

```mermaid
stateDiagram-v2
    [*] --> ボード画面
    ボード画面 --> タスク追加モーダル: ＋ボタン押下
    タスク追加モーダル --> ボード画面: 保存
    タスク追加モーダル --> ボード画面: キャンセル

    ボード画面 --> タスク編集モーダル: タスクカードをクリック
    タスク編集モーダル --> ボード画面: 保存
    タスク編集モーダル --> ボード画面: 削除
    タスク編集モーダル --> ボード画面: キャンセル
```
